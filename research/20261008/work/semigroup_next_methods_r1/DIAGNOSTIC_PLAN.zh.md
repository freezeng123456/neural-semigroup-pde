# 下一方法选择前的固定模型诊断

日期：2026-10-04。使用阶段 B 已回收的最终模型；不更新参数，不重选检查点。

## 要区分的问题

1. 误差是否主要落在宽 20、12 模式 FNO 的显式低频范围之外？若不是，不以“截断高频”作为优先扩展模式数的理由。
2. 真实状态上的单步误差和自由滚动误差相差多少？这个比较使用同一开发轨迹、同一时滞和同一物理相对 L2，避免将训练 loss 与另一口径的长程 loss 相除。
3. 滚动误差的逐步变化主要来自新的局部误差，还是已有误差的放大？沿实际误差方向测量，不升级为全局稳定性结论。
4. 空间均值漂移占误差能量多少？这决定仅投影均值是否可能解释明显改善。

## 在执行前固定的分析

- 四臂、三个种子，共 12 个已保存的开发预测：全 20 条轨迹、全部 50 个正时间快照；报告物理空间误差和二维傅里叶误差能量。
- 傅里叶分组：零模式、`max(|kx|,|ky|)<4`、`4<=max<8`、`8<=max<12`、`max>=12`。使用完整正交 FFT 和 Parseval 检查。`max<12` 是对称诊断区域，并不精确等同作者 rFFT 的两个矩形切片；FNO 的逐点非线性也能生成范围外模式。
- 对主基线 GDSG-500 的三个最终种子，给定每个真实开发状态，预测下一个快照（共 3,000 个转移）；同时从原 GPU 保存的上一预测状态做一次 CPU 前向（另 3,000 个转移）。保留所有物理输出。
- 用 CPU 结果分解 `e_next = q + d`：`d=G(u)-u_next`，`q=G(u_hat)-G(u)`。检查恒等式、CPU/GPU误差、方向增益 `||q||/||u_hat-u||`、`q` 和 `d` 的夹角、局部误差随时间变化及各频带能量。第一个转移的输入误差为零，增益标为未定义，不加 epsilon 改成数值。
- 匹配精度验收：CPU 从保存上一状态前向所得输出与原 GPU 下一状态的逐转移相对 L2 最大值应不超过 `2e-5`，否则停止依赖该结果做递推解释。
- 检查全部使用的原始输入、检查点、预测和源码 SHA-256 在执行前后不变；输出存到新的目录，不覆盖阶段 B 证据。

## 判断边界

这是探索性方法选择诊断，不是预注册方法优越性检验。频带占比不证明训练某个频带会降低长程误差；方向增益也不是最大的 Jacobian 奇异值。开发集已经用于方法选择，不能用于后续新方法的盲测确认；公开 test 同样已经查看。新的确认性结论需要新的独立轨迹和冻结的选择规则。

本轮只做诊断、文献核对和可执行候选准备。新 GPU 训练使用单独的实验协议。
