# 两条路线的理论、结构限制与判定

2026-10-05。本文补充已经冻结的首轮方案，不改变上传包中的代码、数据或24项训练矩阵。

## 1. 两步真值监督解决什么问题

记真实的连续三个快照为 (z_0,z_1,z_2)，对应物理时间间隔为 (h_1,h_2)，网络预测记为 (G_\theta(z,h))。误差函数 (d(y,p)) 沿用作者代码的相对 L2 定义，参数顺序和分母也保持一致。

四个主要拟合目标为：

- first：(d(z_1,G(z_0,h_1)))。
- teacher2：两个真实输入的一步误差平均，第二项为 (d(z_2,G(z_1,h_2)))。
- rollout2：第二项改为 (d(z_2,G(G(z_0,h_1),h_2)))，梯度贯穿两个预测步骤。
- pushforward2：第二项仍从模型预测出发，但对第一个预测停止梯度。

总目标均为“拟合目标与原 GDSG 目标的平均”。GDSG 使用相同随机盒状态和时间配点；正序、逆序组合与直接预测之间的两个相对误差取平均。原作者代码把组合预测放在误差函数第一个参数位置，因此分母不能随意改成直接预测的范数。计算图和配点顺序已独立核对。

这里的机制是假设：真实输入的一步训练对递推中出现的模型状态覆盖不足，而两步监督能把第二步误差反传给产生该状态的模型。teacher2 控制新增真值覆盖；rollout2 与 pushforward2 的差异控制贯穿第一步的梯度。多步监督、teacher forcing 和停止梯度的 pushforward 都是既有方法。本轮不把它们称为新算法。[DUE §3.1](https://arxiv.org/html/2504.10373v1#S3.SS1)、[MP-PDE](https://arxiv.org/html/2202.03376v3)

有限训练样本上的小损失不推出全域半群律、稳定性或测试精度。原有效基线保留；本轮比较同一2000个窗口，另有宽20→40、500→1000轮对照，分别检查容量和训练长度。历史 Stage B 的窗口不同，不能直接作为本轮配对比较。

## 2. 自主生成元为什么能产生半群

在固定64×64网格上，学习有限维向量场

\[
\dot z=F_\theta(z),\qquad z\in\mathbb R^{4096}.
\]

自主表示右端项只依赖当前状态。若解唯一，沿同一向量场先走 (s) 再走 (t)，与直接走 (s+t) 是同一解。因此精确流满足

\[
\Phi_0=I,\qquad \Phi_{s+t}=\Phi_t\circ\Phi_s.
\]

本实现的空间骨干由有限维 Fourier 线性算子、共享线性层和 GELU 组成。对于有限权重，这些线性算子的范数有限；GELU 的导数绝对值有全局上界，例如 (1+1/\sqrt{2\pi e})。有限次复合与求和给出 (F_\theta) 的有限全局 Lipschitz 常数 (L)。进一步有

\[
\|F_\theta(z)\|\le \|F_\theta(0)\|+L\|z\|.
\]

由唯一性和上述线性增长界，理想实数运算下的有限网格 ODE 在每个有限时间区间均存在唯一解，得到全局的精确流。这是对冻结协议中“局部 Lipschitz、存在区间内半群”的补充论证。它不证明对应连续 PDE 的一致性、耗散性、误差小，也不保证浮点计算不溢出；这个 Lipschitz 上界可能很大。

带绝对时间的对照为 (\dot z=F_\theta(z,t))。它满足两参数流的拼接律，需要同时记录起止时刻；单独在状态上一般不是一参数半群。增加时钟状态可以将它改写为自主系统，但这改变了状态空间。

实际推断用 RK4，数值映射只有近似的组合一致性。最终模型必须做1、2、4、8子步比较，分别报告求解器细化误差、组合缺陷、真值误差和向量场调用次数。小组合缺陷不能代替小真值误差。

## 3. 生成元标签的局限

训练借鉴 CFO 的样条速度监督，不反传完整积分过程。已核对作者代码实际使用三点非均匀导数模板，主执行数据采用此模板；五点仅作敏感性对照。[CFO 论文](https://arxiv.org/html/2512.05297v1)、[作者实现](https://github.com/shannon-hou/CFO_official/tree/3f208668ad67ca4643ef22dfeda29b4c0bf56c30)

同一训练数据上，三点与五点的一阶导数平均相对差为6.26%，二阶为11.81%。这是模板敏感性，不是真导数误差上界。快照间隔约0.5至1.5，尚未用经过验证的 PDE 瞬时右端项独立校验代理标签。标签来自裁剪后的归一化数据，周围快照也参与端点导数估计；因此跨路线的精度比较不能把收益单独归因于自主性。

## 4. 新确认的空间对称性限制

作者代码的 `osg_fno2d` 只输入状态和空间恒定的时间特征，没有输入空间坐标或固定外力场。周期 Fourier 线性层与整数网格平移交换，共享逐点线性层、GELU、全局标量归一化也与平移交换。所以对任意整数平移 (T_a)，理想运算下

\[
G_\theta(T_a z,h)=T_aG_\theta(z,h),\qquad
F_\theta(T_a z)=T_aF_\theta(z).
\]

增加网络宽度仍会保留这条性质。两个新生成元臂也继承同一限制；加入空间恒定的绝对时间特征不会消除它。

而 [DUE §5.6](https://arxiv.org/html/2504.10373v1#S5.SS6) 声明的方程含固定外力

\[
f(x)=0.1[\sin(2\pi(x_1+x_2))+\cos(2\pi(x_1+x_2))].
\]

在固定外力下，平移状态并不同时平移外力。记平移等变的平流、黏性部分为 (A)，则真实右端项 (V(z)=A(z)+f) 满足

\[
V(T_a z)-T_aV(z)=f-T_af.
\]

当 (T_af\ne f) 时，真实右端项与模型的全域空间对称性不相容。更简单的例子是零涡量：真实初始导数为非恒定的 (f)，而当前模型在空间恒定输入上只能产生恒定输出。因此对包括这些状态的全域问题，单纯扩容无法消除表示限制。这个推导假定论文给定方程、周期条件以及平移等变的速度重建；本次没有重新验证数据生成器。

只读诊断使用 Stage B 已完成的 GD500 种子0最终检查点，以及两个生成元本地 smoke 检查点。后两者保存于第1次更新，尚未完成训练。对4个开发轨迹的第25快照和5种整数平移：

| 对象 | 最大相对 L2 平移缺陷 |
|---|---:|
| GD500 最终模型 | (5.60\times10^{-8}) |
| 自主生成元 smoke 状态 | (7.48\times10^{-8}) |
| 时间条件生成元 smoke 状态 | (7.59\times10^{-8}) |

零物理状态上的输出空间标准差分别为 (3.47\times10^{-10},0,0)。所有参数、数据和源文件的哈希保持不变，新增优化更新数为0。

论文外力在单轴平移8格后相对 L2 变化为0.76537；平移(8,8)后为1.41421；平移(8,-8)保持不变。数值结果与解析式 (2|\sin(\pi(a_1+a_2)/64)|) 相符。

**这些结果不能证明这个限制造成了当前约1%的轨迹误差。** 原轨迹分布可能在状态中包含外力的空间相位。这里没有生成移位初值的独立 PDE 真值，也没有给出原开发分布上的误差下界。

## 5. 后续可证伪的结构检查

本轮24项矩阵保留，用于检验同一骨干上的两步监督、宽度、训练长度和时间条件。若收益有限，下一步优先比较显式外力输入与原骨干，并做参数量接近的对照。对周期问题，固定外力通道能提供缺失的空间相位；周期坐标的正余弦通道也可作为另一个对照。

确认阶段需先校验数值参考，再用同一固定外力求解原初值和若干平移初值。比较原分布误差、平移初值误差、向量场误差和推断成本。如果新增外力输入在这些条件下没有稳定收益，就削弱“缺少空间相位是主要瓶颈”的假设。尚未准备或启动这组新增 GPU 训练。
