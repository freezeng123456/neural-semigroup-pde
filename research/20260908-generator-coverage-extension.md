# Bounded follow-up screen, specified before launch

The legacy checkpoint diagnosis found 30-42% of long reference states outside the global initial-state range, and final weights outperforming the one-step-selected weights for both A and B. The initial 400-update screen is running while this extension is specified. These observations motivate a finite 72-cell extension, not an open-ended search.

All 72 cells use midpoint reaction, four reaction evaluations per map, 2000 Adam updates and three seeds; A/B share physics, architecture and losses. Data offset 10000 gives fresh train/validation/test/stress seeds relative to the first screen. Once used, these new tests are exploratory and must not be called untouched formal confirmation. Final, best validation checkpoints, epoch120 and epoch400 are saved. The epoch400-to-final comparison isolates optimization duration within the same run/data; cross-screen comparisons alone do not isolate duration because data changes.

1. **long-L4**: initial, teacher, detached, unroll; 24 cells. Uses the original state-MSE loss and L=4, with the same 128 snapshot predictions per update and 128 versus 32 independent initial states as documented in the main protocol.
2. **rate-L4**: same four methods and exact same cache as long-L4; 24 cells. Divide each snapshot residual by the assigned transition lag before squaring. This gives lag weighting proportional to `1/tau^2`; it uses no true source labels. For detached/full rollout, the divisor is the transition lag at every supervised step, not the cumulative elapsed time. The comparison changes lag weighting, so an improvement must not automatically be attributed to better generator identification without measuring it.
3. **long-L8**: teacher, detached, unroll and initial_repeat; 24 cells. State-MSE loss, L=8, same 128 prediction budget. This uses 16 nested initial states with eight snapshots, compared with 32 initial states with four snapshots for L4. It deliberately trades initial-state diversity for trajectory depth. The repeated-initial control has 16 unique pairs repeated eight times; it is an explicit diversity/reuse control. Reuse the same fresh-data seeds; verify identical initial pools and matching first four snapshots between L4/L8. Do not present L8 as an isolated temporal-gradient experiment. The detached/full contrast within L8 does isolate temporal gradient propagation with the same forward recurrence and targets.

Selection, primary MSE endpoints, A/B gate, physical diagnostics and full artifact recovery remain as frozen in the main protocol. No test-based mode selection or architecture/hyperparameter adjustment occurs inside these 72 cells. Stop after this extension and report both successful and negative contrasts.
