# Burgers / KS 三臂 benchmark r2

本轮比较同一固定间隔流映射的三种监督训练方式，检验两步递推训练能否改善自由滚动预测；参考积分细化原因和原失败证据见 `REVISION.md`

## 固定训练目标

- first：用真值初态预测第1步，仅计算第1步监督损失，每更新1次 forward
- teacher2：分别从真值第0步和第1步预测下一步，两项监督损失取平均，每更新2次 forward
- rollout2：从真值第0步递推预测两步，两项监督损失取平均，第二步保留经过第一步预测的完整梯度，每更新2次 forward

损失为逐样本归一化状态的相对 L2，再对批次取平均，真值范数分母下限1e-12；三臂共用相同数据字节、标量训练集归一化、初始模型、完整500轮 shuffle 和固定最终端点，不加半群组合正则

teacher2 与 rollout2 匹配两个标签、两次 forward 和更新数，差异同时包含预测中间输入和跨步梯度路径，结果解释为完整训练方案比较

## 数据与参考积分

两种 PDE 都使用官方 APEBench 0.1.1 / Exponax 0.1.0 的固定源码，来源文件和包内源码 SHA 锁定于 `reference/SOURCE_LOCK.json`，参数、审核门槛与生成规则见 `reference/REFERENCE_PROTOCOL.zh.md`

物理观测间隔均为0.1，周期网格256点，Burgers 标签每宏步1子步，KS 标签每宏步2子步；初态热身固定原官方每宏步1子步，Burgers 热身0步、KS 热身500个宏步

每 PDE 使用128条训练轨迹、32条开发轨迹、64条独立封存测试轨迹，训练50次转移、开发和测试200次转移；从128×49个连续两转移窗口中固定无放回抽取2000个窗口，所有种子和三臂共享

参考积分以 float64 运行后保存 float32 物理状态，归一化参数仅由全部训练状态拟合；细网格投影用于数值审核，训练标签直接来自256点闭合数值映射

## 模型、预算与随机性

固定原生1D FNO，宽度32、Fourier 模态16、深度4、投影宽度128、GELU，共139713个实数参数分量；模型仅接收当前状态，固定物理间隔不加时间或历史通道

每 PDE × first / teacher2 / rollout2 × seed0 / 1 / 2，共18次训练；每次500轮、每轮100次更新、batch20、共50000次 Adam 更新，初始学习率0.001，余弦调度在固定最终更新降至0

first 每次训练50000次 forward，teacher2 与 rollout2 各100000次 forward；18次合计900000次优化更新、1500000次训练 forward

配对初始化种子为训练 seed，shuffle 为30000+seed；固定最终端点评估，每25轮记录开发集200步自由滚动曲线，禁止按开发集最优轮次选择端点

## 执行与验收

运行根固定为 `/data02/run01/scv7tsq/neural-semigroup/20261028-burgers-ks-r2`，工程执行流程见 `operations/README.md`

先完成独立数值审核，再在一个真实分配的 V100 上完成工程预检，要求9项检查、66次真实优化更新、恢复后精确下一次更新一致及开发指标复算，工程预检不计算封存测试成绩

正式训练分为9项 Burgers 与9项 KS 两波，每波最多2项并发；前一波全部真实 `COMPLETED 0:0`、500轮和50000更新及文件哈希核对通过后，才提交后一波

任意失败保留紧凑真实证据并停止后续启动，只能取消本矩阵仍未开始的任务，不替换种子、不自动重试、不恢复旧实验

全部18个固定最终端点和真实 Slurm 成功状态封存后，单次分配 GPU 的回放作业先精确复算开发指标，再对每个模型执行一次200步封存测试，回放优化更新为0

主比较为各 PDE 的 rollout2 / teacher2 三种子联合滚动误差几何平均，预定实用门槛为≤0.90、至少2/3种子改善、全部最终滚动有限；teacher2 / first 与 rollout2 / first 为补充比较，报告逐种子结果、训练时间、forward 与显存成本

物理指标先在 float64 计算逐轨迹全部等权快照的联合相对 L2，再取轨迹平均，包含初态归一化往返快照；同时记录各时间步误差与最终误差，不把开发集探索解释为独立泛化或统计显著性

结果写入 `analysis-r2`，仅回收紧凑源码、配置、回执、标量曲线、指标和必要日志，归档 `recovery/burgers-ks-compact-r2.tar.gz`；权重、优化器、原始预测和数据缓存保留远端，不下载或上传 GitHub
