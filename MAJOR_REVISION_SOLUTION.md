# Major Revision Solution

This document turns the two review reports into an implementable revision program. It distinguishes mathematical corrections, code changes, validation, and experiments that still require genuine reruns. No missing result is inferred or fabricated.

## 1. Revision principles

The project contains five different layers. Each claim and metric must name its layer.

1. **PDE layer:** the exact solution semigroup `S_t`, its invariant set, and its physical energy.
2. **Exact semidiscrete layer:** the flow of the spatially discretized ODE.
3. **Exact latent layer:** the continuous flow generated by the learned latent ODE.
4. **Numerical layer:** RK4 or another finite-step implementation of either ODE.
5. **Empirical layer:** finite datasets, trained checkpoints, and reported metrics.

An exact statement at one layer does not automatically transfer to another layer. The revised paper and evaluation API keep these layers separate.

## 2. Critical transfer-theorem issue

### Problem

The previous theorem used the same notation for the exact semidiscrete flow and a discrete time integrator. Its proof mixed a continuous-flow comparison with a one-step discrete Gronwall argument, and an earlier version dropped a numerical defect term. It also compared vectors in `R^N` directly with states in the PDE space without explicit projection or reconstruction operators.

### Implemented solution

The manuscript now defines:

- `P_N`, which projects or samples a PDE state into `X_N = R^N`;
- `I_N`, which reconstructs a semidiscrete state in the PDE space;
- `\widetilde S_t^N`, the exact semidiscrete ODE flow;
- `Q_{Delta t}^N`, a numerical semidiscrete one-step map;
- `Phi_theta`, the exact latent flow;
- `\widehat Phi_{theta,h}`, its numerical implementation.

The transfer theorem first compares the two exact finite-dimensional flows. If their generators differ by at most `epsilon_match` on a common invariant neighborhood and the semidiscrete generator is `L_T`-Lipschitz, continuous Gronwall gives

```text
||Phi_theta(P_N u0,t) - \widetilde S_t^N(P_N u0)||
    <= epsilon_match * chi_L(t),
```

where `chi_L(t) = (exp(L t)-1)/L`, with `chi_0(t)=t`. Reconstruction stability and the independent spatial convergence estimate then give the PDE-space bound. Numerical time-integration errors are added in separate proposition and corollary statements.

### Validation required

- Compile the LaTeX paper and resolve every reference.
- Check that no remaining theorem uses `S_t^N` ambiguously.
- For each benchmark, document the concrete `P_N`, `I_N`, norm, compact interior set, and semidiscrete convergence source.

The last item is PDE-specific analytical work; the general theorem cannot manufacture it.

## 3. Continuous versus numerical semigroup properties

### Problem

The exact semigroup law belongs to the exact autonomous ODE flow. RK4 defines an approximate family and generally has a nonzero composition defect.

### Implemented solution

The paper now calls the measured quantity the **numerical semigroup defect**. The evaluation code is required to report:

- absolute defect;
- relative defect with an explicit denominator convention;
- the ODE substep count;
- an optional substep-refinement comparison;
- confirmation that temporary changes to `model.ode_steps` are restored.

The archived value near `1e-14` remains documented as an empirical floating-point observation, not an exact guarantee.

### Acceptance criterion

For at least two ODE substep counts, report the defect on the same states and time pairs. A result may be described as consistent with integration accuracy only if the refinement behavior supports that description.

## 4. Learned energy versus physical energy

### Problem

The architecture dissipates the induced learned energy

```text
E_theta(u) = Psi_theta(g^{-1}(u)).
```

This does not imply dissipation of the semidiscrete PDE energy `E_N` or physical energy `E`.

### Implemented solution

The manuscript now states this distinction immediately after defining `E_theta`. The evaluation API separates:

- learned/induced-energy monotonicity, evaluated through `model.energy`;
- physical-energy monotonicity, evaluated only when a caller supplies `physical_energy_fn`;
- a clear `not evaluated` status when no physical functional is supplied.

The legacy `energy_mono_frac` field may remain as a compatibility alias, but new results must use semantically explicit keys.

### Acceptance criterion

No table may label learned-energy monotonicity simply as physical energy preservation. Fisher--KPP and Allen--Cahn reruns should provide their discrete physical energy functions and report both diagnostics.

## 5. Expressivity claim

### Problem

The previous universal-approximation proposition asserted more than its proof established. The implemented class uses a shared scalar potential, prescribed interaction graph, Gram-constrained couplings, local diagonal mobility, and a bounded decoder. Independent approximation statements do not imply density in arbitrary smooth vector fields.

### Implemented solution

The universal claim has been replaced by a proved componentwise error bound for an **architecture-compatible target**:

```text
F_N^*(u) = -Dg K^* grad Psi^*.
```

If `K_theta` and `grad Psi_theta` approximate `K^*` and `grad Psi^*` on a compact latent set, the generator error is bounded by

```text
M_g (M_K epsilon_Psi + M_Psi epsilon_K).
```

The manuscript explicitly leaves component density under the implemented parameter restrictions as an open problem.

### Future route to a stronger theorem

One of the following must be completed before restoring a universality claim:

1. Prove simultaneous `C^1` approximation for the exact shared-potential and local-mobility classes, plus a representability theorem for the Gram-constrained edge weights.
2. Replace Gram-constrained edge coefficients with independently parameterized positive symmetric edge weights and prove density for the resulting graph-energy class.
3. State and prove universality only for a narrower target class whose potential, graph interactions, and mobility already have the architecture-compatible form.

## 6. Global-flow gap and `beta_V`

### Problem

The archived experiments use `beta_V=0`, while the available global-flow theorem relies on a coercive quadratic contribution with `beta_V>0`.

### Implemented solution

The paper no longer treats finite-time non-blowup as proof of global existence. The experiment code exposes a fixed non-trainable `beta_V_floor` and records both the floor and the post-training effective coefficient. A positive floor, unlike a merely positive trainable initialization, cannot be optimized back to zero. Existing checkpoints remain strictly loadable because the floor is not added to the state dictionary and the archived default is not silently changed.

### Required experiment

Run a coercive Fisher--KPP benchmark with the same data split and report:

- prediction metrics;
- numerical semigroup defects and substep refinement;
- learned and physical energy diagnostics;
- latent norm and maximum vector-field norm over the evaluated trajectories;
- `beta_V`, seed, ODE substeps, and all loss weights.

Only a run with a recorded positive `beta_V_floor` may be cited as an experimental configuration covered by the stated coercive sufficient condition.

## 7. Viscous Burgers scope

### Problem

Periodic viscous Burgers dissipates its physical `L^2` energy, but the convective term is transport/skew rather than a pure gradient flow. It is outside the current expressivity result.

### Implemented solution

The manuscript treats Burgers as an out-of-class empirical stress test and removes the claim that the gradient architecture theoretically covers it.

### In-class extension

A feasible extension is

```text
z' = (J_theta(z) - K_theta(z)) grad Psi_theta(z),
```

where `J_theta(z)^T = -J_theta(z)` and `K_theta(z)` is positive semidefinite. The skew term contributes zero to `d Psi_theta/dt`, while representing a conservative transport component. This extension requires a separate implementation, structural proposition, and benchmark; it is not claimed as completed here.

## 8. Time alignment and metric denominators

### Problem

The original Fisher--KPP evaluation compared a model step of `tau=0.1` with a reference snapshot spaced by `0.005`. Rounding an incompatible `tau/reference_dt` can silently compare different physical times. The evaluator also divided accumulated metrics by requested steps even when a trajectory ended early.

### Code solution

The revised evaluator must:

- validate that `tau/reference_dt` is within a documented tolerance of a positive integer;
- fail with a descriptive error when exact stored-snapshot alignment is impossible;
- derive the maximum valid rollout count from the aligned reference stride;
- divide each aggregate and per-step statistic by the number of comparisons actually performed;
- record the aligned stride and evaluated horizon in output metadata.

Unit tests use toy trajectories so this logic is checked without retraining or GPU access.

## 9. Reproducibility and architecture-only ablation

### Problem

Archived runs did not record fixed seeds. Claims that properties came from the architecture also require confirmation that auxiliary semigroup and energy losses were disabled.

### Code solution

The revised experiment utilities seed Python, NumPy, PyTorch, and CUDA where available. Major runners record:

- seed;
- `tau` and `reference_dt`;
- `beta_V` and ODE substeps;
- `alpha_rollout`, `alpha_energy`, and `alpha_bound`;
- device and checkpoint provenance.

Lightweight tests verify that `alpha_rollout=0` and `alpha_energy=0` do not invoke the corresponding loss functions.

## 10. Incomplete tables

### Problem

Allen--Cahn and latent Burgers rows contained visual placeholders while surrounding prose stated conclusions.

### Implemented solution

The placeholders are replaced by `Not reported`, and unsupported conclusions are removed. Existing baseline numbers are retained for provenance. Values will be inserted only after corrected seeded reruns.

## 11. Rerun protocol

Use the same protocol for Fisher--KPP, Allen--Cahn, and any future in-class benchmark.

1. Freeze a data split and record its seed or checksum.
2. Record every configuration field listed above.
3. Validate `tau/reference_dt` before training or evaluation.
4. Train at least the archived configuration and one coercive `beta_V>0` configuration for Fisher--KPP.
5. Evaluate rollout error, boundary violation, absolute and relative numerical semigroup defect, learned-energy monotonicity, and physical-energy monotonicity.
6. Repeat over documented training seeds; do not use trajectory count as a substitute for training-seed variation.
7. Run a substep-refinement diagnostic on each selected checkpoint.
8. Save raw per-sample/per-step data and aggregated JSON with configuration metadata.
9. Populate manuscript tables from the generated JSON, not by manual transcription.

## 12. Completion criteria

The major revision is complete only when all of the following hold:

- the paper compiles without undefined references;
- all lightweight experiment tests pass on CPU;
- no evaluator silently rounds incompatible physical times;
- numerical and exact semigroup statements are distinct;
- learned and physical energy fields are distinct;
- a seeded positive-`beta_V_floor` Fisher--KPP result is available;
- Allen--Cahn placeholders are replaced by generated results;
- Burgers is either kept explicitly out of class or evaluated with a separately proved skew-gradient extension;
- every table row is traceable to a committed JSON result and recorded configuration.
