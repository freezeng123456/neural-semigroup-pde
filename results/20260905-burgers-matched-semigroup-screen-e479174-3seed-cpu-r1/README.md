byte-identically by the launcher from `--data-seed 20260902`; the expected

## Reproduce

```bash
./launchers/burgers_screen_cpu.sh /path/to/work-root
python3 experiments/aggregate_burgers_semigroup_screen.py \
  /path/to/work-root/cells/s31415/summary.json \
  /path/to/work-root/cells/s271828/summary.json \
  /path/to/work-root/cells/s161803/summary.json \
  --output /path/to/work-root/aggregate.json
```

A cell that already holds its `done` marker is never retrained, so rerunning
the launcher against a completed root only rechecks cache immutability and
cell completion.

## Integrity

- The data-cache digest `30c8443e37fa9b0d97e2b964699e8c0044f8f637232acf29abf915f19ac2de8d`
  is identical before and after execution.
- All three cells recorded `EXIT_CODE=0` and `DONE`.
- Both models of every cell report 1,313 parameters, and the query-time model
  is initialized from the autonomous model's parameter tensors.
- Every composition cell gives both paths the same right-hand-side evaluation
  count; the aggregator rejects the matrix otherwise.
- Checkpoint selection used mean one-step validation MSE on the four training
  lags only.  The unseen lags `0.04` and `0.08` and the reported horizons
  `0.4` and `0.8` never entered selection.

## Known deviation

No CUDA device was available on the execution host, so the run is CPU-only and
the protocol's "confirm CUDA execution" smoke item could not be satisfied.
All other smoke items were checked.  See `protocol_deviations` in
`run-card.json`.
