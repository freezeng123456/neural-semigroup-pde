# SCNet 半群机制探索：首批预注册

## 研究问题

上一轮探索发现部分自主反应模型存在长期预测优势，但没有统一状态网格上的反应项识别优势。本轮检验三个不同用途；不复用上一轮测试数据来选择权重。

1. **不规则、少量、带测量噪声的快照。** 已知扩散与负三次项，未知其余反应规律。128 或 16 个独立初始状态，时长为 0.03/0.07/0.13/0.23，输入和输出同时加入固定高斯测量噪声（标准差 0 或 0.01）。自主生成元与时长条件生成元使用完全相同的样本、噪声和初始化。检验有限观测下自主性是否改善未见时长与长期预测。四个离散的不等间隔不是任意连续时间采样。
2. **已知物理算子重新组合。** 上述权重仅在扩散系数 0.02 训练；直接替换已知热算子中的系数为 0.005 与 0.08，权重不改，测试时长和物理终点保持一致。检验反应规律是否能被迁移复用。此设置假设新扩散系数已知，不能声称识别未知扩散或任意跨 PDE 泛化。两种模型都获得该已知算子。
3. **非自主 PDE 的时钟扩充。** 加入外力 0.3 sin(2πt)，训练仅提供状态快照，模型不直接获取真实外力值。对照为自主模型、请求时长条件模型、真实时钟相位模型。时钟模型得到已知周期对应的 sin(2πt), cos(2πt)，这是显式先验；它每个积分阶段更新物理时钟，重启时使用累计时间。此比较检验状态扩充在该周期外力上的作用，不证明任意未知频率、未知外力或任意非自主问题可恢复。

## 冻结设置

- 33 个训练 cell：3 seeds (42/123/2026) × [2 样本数 × 2 噪声 × 2 模型 + 3 外力模型]。
- 空间 N=64，周期域长度 2π；参考为固定空间网格上的 FP64 RK4，dt≤0.002。dt≤0.001 的配对检查须相对 L2≤1e-5；这只验证时间误差，不是网格收敛或连续 PDE 误差证明。
- 共享已知扩散、负三次项和单隐层32宽网络。名义参数均193；自主/时长/时钟有效参数分别97/129/161，不能称为有效容量完全相同。
- 每个映射4个 Strang 分裂子步、每步2次显式中点反应项求值。相同设置的模型每次更新预测相同 n 个场，调用 n×64×8 次标量反应规律；报告实测时间、参数数和调用数。不同 n 的学习曲线不称为相同数据预算。
- Adam，学习率0.003，2000更新，梯度范数截断10。固定第1、每100及最后更新进行独立验证。按验证集0.6/1.2终点、0.12时长的MSE几何平均选择权重；保留初始、最终和最优权重。
- 主测试：干净独立初始条件，未见步长0.06/0.12/0.24，终点0.6/1.2/2.4。另报告高幅值初始条件。所有终点均有独立参考，不将组合自一致性当标签。
- 同一个 seed 的16样本是128样本的前缀；噪声逐元素固定。验证、测试和压力测试使用各自固定的新种子。
- 外力训练时钟起点0/0.25/0.5/0.75；时长与起点作平衡组合，训练总时间最多0.98。测试从0推进至2.4，因此包含新周期，但模型已获得周期先验。

## 指标与判定

主指标为常规测试中1.2/2.4终点、0.06/0.12步长的MSE几何平均。0.24步长单列外推。三个seed成对报告，随后计算几何平均A/B；候选要求汇总≤0.9、至少2个seed≤0.9且无seed>1.05。候选不等于经过多重比较校正的显著性结论。

不规则观测比较自主/时长；算子迁移分别在每个新扩散系数比较同一对模型，必须同时列出绝对MSE与相对L2；外力分别比较时钟/自主及时钟/时长。任何只有分母退化而分子没有改善的受控变化必须明确标注。

独立诊断：统一u∈[-1.3,1.3]反应项误差；数值组合误差；4倍积分工作量下的长期误差。组合对比固定总中点子步数8/16/32，直接0.24和两段0.12使用相同基本步长。自主/正确时钟模型在这种严格对齐路径上可以仅剩舍入误差；这不能被当成连续时间泛化或预测优势证据。

报告|u|>1.5的观察比例、最大状态、物理自由能的单调比例和正增量。1.5是诊断阈值，不是已证明不变区间。能量按每个扩散系数计算；外力问题的该能量不预期单调，不使用其单调性筛选外力模型。
