# SCNet 时钟信息匹配对照：观察首批结果后的机制核查

2026-09-09。该扩展是在看过首批33个实验后设计的探索性检验，不能称为首批预注册确认。

首批周期外力实验中，真实时钟模型相对缺少物理时钟的两个模型具有约10倍MSE收益。该结果同时改变了可用信息与结构，不能据此归因于自主性。

新增 clock_query 模型，同样输入 u、sin(2πt)、cos(2πt)，并额外允许使用请求时长 q。其网络、初始化、已知扩散、已知负三次项、积分工作、优化器、更新数、数据缓存、验证选择和评估端点与首批保持一致。原 clock 模型将 q 输入置零；clock_query 使用 q/0.23。名义参数均193，有效参数分别161与193。

只新增3个训练cell，seed=42/123/2026；使用原始forced/128/无噪声缓存，SHA逐字相同。Adam 0.003、2000次更新、4个中点分裂子步。权重只按原验证指标选择。新commit先通过单卡2更新smoke，再运行3个完整训练，独立目录，原33个训练和权重保持冻结。

主比较是 clock / clock_query 的主预测MSE比（test，nu=.02，t=1.2/2.4，lag=.06/.12）。各seed与几何平均全部报告，参考原候选门槛GM≤.9、至少2seed≤.9、无seed>1.05。由于测试集已查看，该门槛只用于探索性机制筛查，不产生独立确认或多重检验校正后的显著性证据。

如果两者相近或clock_query更优，则将首批大收益主要解释为时钟信息的作用；如果clock更优，则只能说在相同物理时间信息下，自主结构出现额外收益候选。必须同时列出绝对MSE、反应项误差、计算时间和数值组合误差，不用组合缺陷代替预测精度。
