# Current method: novelty and prior-art audit

## Scope and bottom line

This note audits the implementation currently present in the repository and the claims supported by the current Allen–Cahn results. It is a prior-art screen, not a patentability opinion and not a claim of global novelty. The safest conclusion is:

> The individual ingredients are substantially known. The potentially novel contribution is the particular combination of an autonomous latent flow, a dissipative gradient-flow parameterization, bounded decoding, periodic/local decoded-state coupling, and a fixed Allen–Cahn physics anchor, together with a reproducible locked-test protocol. That combination is not established as new by this search; it requires a broader search and, scientifically, a matched non-semigroup control.

The current repository does **not** establish that semigroup structure itself caused the observed accuracy gain. The completed N=128 ablation is an autonomous flow with versus without the fixed double-well anchor; it is not a direct-map-with-the-same-physics versus autonomous-flow comparison.

## What is actually implemented

The current `LatentSemigroupNet` uses:

1. `u = m+(M-m)sigmoid(z)`, with logit encoding and sigmoid decoding.  In the current Allen--Cahn configuration `m=-1, M=1`, so this gives the architectural output range `-1<u_i<1` (up to numerical clamping).
2. An autonomous latent ODE, integrated by fixed-step RK4:
   \[
   \dot z=-K_\theta(z)\nabla\Psi_\theta(z).
   \]
3. A diagonal positive mobility generated by a local periodic stencil MLP, implemented as `softplus(K_net(z)) + 5e-3`.
4. A latent potential consisting of a sum of scalar MLP potentials plus pairwise quadratic differences on a periodic local interaction mask; coefficients are constrained nonnegative through softplus of embedding inner products.
5. A fixed Allen–Cahn double-well/physics anchor in the `latent_physics_anchored_periodic` variant. The repository’s current N=128 protocol sets `alpha_rollout=0` and `alpha_energy=0`; the semigroup prior therefore comes from the autonomous generator, not from a separately active semigroup-loss term.
6. Repeated composition of the same autonomous flow for rollout. Exact continuous flow composition is a mathematical property of a sufficiently well-posed autonomous ODE; the finite RK4 map has a numerical composition defect and must not be called an exact semigroup without qualification.

The above facts are evidenced by `experiments/models.py`, `README.md`, and `docs/research/SEMIGROUP_BASELINES_LITERATURE.md`. The code does not by itself prove global well-posedness, exact PDE-semigroup recovery, or universal approximation.

## Closest overlaps and how to distinguish them

### 1. Deep-OSG is the most important semigroup precedent

Deep-OSG explicitly learns evolution operators in a semigroup and introduces architecture/loss mechanisms for variable time lags. It is therefore not safe to say that this project is the first to learn a neural semigroup. The defensible distinction is narrower: the present project uses one autonomous latent generator whose vector field is constrained to a positive-mobility gradient flow, adds a bounded decoder and periodic local coupling, and studies a fixed Allen–Cahn double-well anchor. Whether that package is novel must be established by comparing equations, architecture, losses, and experiments—not by naming the components.

### 2. Energy-consistent operators already exist without semigroup structure

Tanaka et al. impose energy behavior on direct neural operators using an energy-consistency penalty. This rules out the claim that the project is the first neural operator to encode dissipation or energy laws. It also motivates the decisive scientific ablation: keep the same Allen–Cahn physics information in a direct time-conditioned map, then remove only autonomy/flow structure.

### 3. Latent ODE plus decoder is established

Fresca et al. already use encoder–latent-dynamics–decoder reduced-order models, and Neural ODEs established continuous vector-field learning. The novelty cannot be “latent ODE with decoder.” It must be the structural coupling and its demonstrated consequence under matched capacity and compute.

### 4. Local/periodic operators are not new in isolation

Local kernels, stencils, graph message passing, and periodic convolutions all have strong precedent. The project should describe its stencil as a specific positive-mobility parameterization, not as a newly invented local operator family.

## Claims currently supported versus unsupported

### Supported by current code/results

- The implementation defines an autonomous latent ODE with a gradient-flow form and positive mobility.
- The sigmoid decoder enforces a numerical output range in the chosen normalized state coordinates.
- The interaction mask is periodic and local; the mobility uses a periodic stencil in the current implementation.
- On the current N=128 Allen–Cahn protocol, the physics-anchor model beats the matched no-anchor autonomous control in all completed seed-by-horizon comparisons; this is evidence for the anchor within this model family.

### Not established by current code/results

- That the project is the first neural semigroup, first latent gradient-flow operator, or first energy-stable Allen–Cahn learner.
- That semigroup structure itself improves accuracy: the current control removes the physics anchor at the same time as the model remains autonomous.
- That the finite RK4 rollout is an exact semigroup.
- That the learned latent energy is the physical Allen–Cahn free energy.
- That the method is globally well-posed or universally approximates all Allen–Cahn solution operators.
- That it is globally state of the art.

## Decisive experiment for a semigroup-centered claim

Use a matched factorial design with the same encoder/decoder, latent width, parameter count, training pairs, optimizer, source/cache, seeds, and vector-field/RK work:

| Model | Physics anchor | Autonomous continuous flow? |
|---|---:|---:|
| A: current model | yes | yes |
| B: current matched control | no | yes |
| C: direct time-conditioned map | yes | no |
| D: direct time-conditioned map | no | no |

The indispensable comparison is A versus C. If A wins only against B, the result supports the double-well anchor, not semigroup novelty. If A and C have similar MSE but A has lower composition defect, better unseen-time interpolation, better long-horizon stability, or stronger physical-energy behavior at matched work, the paper can make a conditional semigroup-structure claim. Also compare a non-autonomous latent ODE (f(z,t)) to separate time homogeneity from continuous-time integration.

## Recommended paper wording

> We propose a bounded, dissipative latent-flow architecture for learning periodic Allen–Cahn evolution operators. The model combines an autonomous latent generator, positive-mobility gradient-flow dynamics, a periodic local interaction parameterization, and a fixed Allen–Cahn double-well anchor. Existing work has studied neural semigroup learning, latent neural ODEs, energy-consistent neural operators, and structured local PDE solvers separately. Our contribution is the formulation and controlled evaluation of this combination on a locked multi-horizon Allen–Cahn benchmark. We claim a conditional structural advantage only if matched direct-map and non-autonomous controls confirm it; otherwise, we claim improved physics-anchored accuracy within the autonomous latent-flow family.

## Search limitations

This is a targeted primary-source screen, not an exhaustive patent/prior-art search. In particular, the Allen–Cahn-specific literature should be searched further for exact phrases such as “Allen–Cahn neural operator double-well,” “gradient-flow neural operator phase field,” and “periodic latent operator Allen–Cahn,” including newly posted preprints and project repositories. No result in this note should be read as proof that no closer work exists.
